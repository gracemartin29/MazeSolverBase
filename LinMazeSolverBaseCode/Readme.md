# Maze Solving Robot
This is a Pololu 3PI project, where a pololu should be able to follow, solve and remember a maze.

## Hardware
- Pololu 3PI
- USB Micro B Cable

## Software
- Arduino IDE
- libraries?

## Other Materials Needed
